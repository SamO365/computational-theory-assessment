## Computational Theory Assessment

'problems.ipynb' is the main deliverable and contains the code, explains and tests for the assessment problem


## Contents

-'problems.ipynb' - main notebook
-'requirements.txt' - python packages required to run the notebook
-'AGENTS.md' - ReadMe for AI Agents
-'.gitignore' - files excluded from github

## Requirements

This project uses Python 3.14.6 and NumPy
Install the required packages using: 

```bash
pip install -r requirements.txt
```

## Setup

Clone the repository using: 

```bash
git clone https://github.com/SamO365/computational-theory-assessment.git
```

Install the dependencies: 

```bash
pip install -r requirements.txt
```

Open the notebook:

```bash
jupyter notebook problems.ipynb
```
